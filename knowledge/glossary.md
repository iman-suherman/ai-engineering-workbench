# Glossary

| Term | Meaning |
|------|---------|
| Workbench | This knowledge + workflow hub (not the source of truth for live code) |
| Registry | `knowledge/service-registry.yaml` mapping names → repos / local paths |
| Finding | Concise answer backed by evidence |
| Compose | Drafting Chat/Jira/support text for human copy/paste |
| Sibling checkout | App/infra repo cloned next to this workbench |
